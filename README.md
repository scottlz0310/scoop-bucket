# scoop-bucket

Personal Scoop bucket for tools created by [@scottlz0310](https://github.com/scottlz0310).

## 使い方 / How to Use

### 1. バケットの追加

```powershell
scoop bucket add scottlz0310 https://github.com/scottlz0310/scoop-bucket
```

### 2. アプリケーションのインストール

```powershell
scoop install <app>
```
